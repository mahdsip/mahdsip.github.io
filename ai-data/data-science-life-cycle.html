Data Science life cycle

Resumen del bundle NPL para preparar, evaluar y mejorar modelos sobre datos tabulares

Este bloque recoge tres PDFs breves centrados en el ciclo real de trabajo sobre tabular data. No sustituyen al material original: aqui dejo un resumen operativo para navegar mejor el bundle y debajo mantengo los enlaces directos a los PDFs tal como estan.

La secuencia es clara: primero preparar bien el dataset y entender sus metricas, despues representar correctamente variables categoricas o texto, y finalmente ajustar modelos, hyperparameters y estrategias de ensemble sin perder de vista outliers, convergence y evaluation.

1. ML Accelerator Tabular Data1

El primer PDF se mueve por la base del pipeline: data augmentation cuando faltan casos reales, data enrichment con nuevas fuentes, transformations de variables y distincion entre problemas de regression y classification. Tambien entra en metricas y validacion, con notas sobre R cuadrado, precision, recall, F1 score, bias frente a variance, EDA, correlacion entre features, missing data, imputacion y feature scaling.

  • Preparacion del dataset antes de modelar.
  • Lectura critica de metricas y datasets no balanceados.
  • Correlacion, missing values e imputacion como parte del baseline.

2. ML Accelerator Tabular Data2

El segundo PDF se centra mas en representacion de features y decisiones de modelado. Aparecen advertencias sobre explosion de columnas al hacer encoding, necesidad de usar jerarquias utiles como ciudad frente a zip, tratamiento de texto con stopwords y Bag of Words, manejo de valores no vistos en inferencia y varias notas comparando KNN, trees y tecnicas de sklearn.

  • Encoding de categoricas sin destruir la dimensionalidad.
  • Text features con BoW y cuidado con stopwords que cambian el significado.
  • Robustez frente a valores nuevos y limites practicos de algunos algoritmos.

3. ML Accelerator Tabular Data3

El tercer PDF entra ya en optimizacion del modelo: combinacion de hyperparameters, minimizacion del error con gradiente, learning rate, local minima y search del mejor vector de pesos. A partir de ahi enlaza con logistic regression para classification, impacto de outliers en regresion, decision trees, bagging, boosting y una referencia final a arquitecturas de neural networks.

  • Tuning y gradient descent como parte de la fase de training.
  • Decision boundary y logistic regression para pasar de regression a classification.
  • Ensembles y arquitecturas mas complejas una vez la base tabular ya esta controlada.
