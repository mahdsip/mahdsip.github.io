Maths Foundations

Pagina resumen con acceso directo a los ficheros completos

Esta pagina mantiene la seccion de maths como una vista general legible. La idea es resumir los fundamentos principales que hay detras de machine learning y data science, dejando el material detallado completo en ficheros PDF separados que se pueden abrir directamente.

1. Basic linear algebra y vector spaces

El primer bloque cubre como se representan los datos antes de entrenar un modelo. Vectors, matrices y tensors definen la estructura de observaciones y features, mientras que transpose, addition, subtraction y vector spaces proporcionan el lenguaje minimo para razonar geometricamente sobre los datos.

  • Vectors como estructuras numericas ordenadas.
  • Matrices como forma natural de trabajo sobre datasets tabulares.
  • Tensors como extension a dimensiones superiores.
  • Operations y vector spaces como base para similitud y distancia.

2. Transformations y matrix models

El segundo bloque pasa de la representacion a la prediccion. Rotation, matrix multiplication y los cambios de base explican como transformar los datos a un espacio mas simple. Desde ahi se entra de forma natural en OLS, Eigen decomposition, PCA y principal component regression.

  • Ejemplos de prediccion tipo regression.
  • Intuicion geometrica para rotating data.
  • Matrix multiplication como lenguaje de linear transformations.
  • PCA y decompositions relacionadas para dimensiones correlacionadas.

3. Probability y testing

Este bloque introduce la incertidumbre a traves de A/B testing, random variables y probability distributions. El objetivo es conectar preguntas reales de producto o negocio con razonamiento estadistico, en lugar de tratar el testing como un tema aislado.

  • A/B testing como herramienta de decision.
  • Random variables como modelo de outcomes inciertos.
  • Discrete y continuous probability distributions.
  • Interpretacion estadistica de los resultados observados.

4. Likelihood y optimization

Una gran parte de machine learning puede verse como la seleccion de parametros que hagan plausibles los datos observados bajo un modelo. Eso lleva desde maximum likelihood estimation hasta negative log-likelihood, derivatives, gradient descent y las tecnicas de optimization usadas en sistemas modernos de ML.

  • Likelihood como principio de ajuste.
  • Loss functions como objetivo de optimization.
  • Derivatives y gradients como herramientas de busqueda.
  • Entrenamiento basado en gradientes y automatic differentiation.

5. Bayes e information

El bloque final lleva probability al terreno de classification y decision making. Bayes theorem, naive Bayes, ejemplos de fraud detection e information theory ayudan a traducir señales debiles en decisiones mas claras bajo incertidumbre.

  • Bayes theorem como actualizacion de creencias a partir de evidencia.
  • Naive Bayes como baseline classifier transparente.
  • Fraud detection como caso de uso practico.
  • Information theory como lenguaje para incertidumbre y señal.
