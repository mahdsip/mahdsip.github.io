XML

eXtensible Markup Language

XML is a markup language that provides a standard, interoperable container and format for messages. It is a subset of SGML that relaxes some of its restrictions. For an XML document to be correct it must be valid (obey the morphological rules of an XML document) and well-formed (obey the syntactic rules defined in its schema).

XSD

Message structure can be defined with several technologies such as DTD, but DTD does not allow mixing structures from different sources, so XSD (XML Schema Definition) is generally used instead as it is richer in that regard. XSD programming is based on namespaces, similar to Java packages. Each namespace groups related elements and attributes, and when defining an element or attribute a connection is created between the fields of that namespace. This model also lets us relate elements from different namespaces.

<?xml version="1.0" encoding="UTF-8"?>
<xsd:schema xmlns:xsd="http://www.w3.org/2001/XMLSchema">
     <xsd:element name="Book">
         <xsd:complexType>
            <xsd:sequence>
                 <xsd:element name="Title" type="xsd:string"/>
                 <xsd:element name="Authors" type="xsd:string" maxOccurs="10"/>
                 <xsd:element name="Publisher" type="xsd:string"/>
            </xsd:sequence>
            <xsd:attribute name="price" type="xsd:double"/>
        </xsd:complexType>
   </xsd:element>
</xsd:schema>

XSL

The eXtensible Stylesheet Language (XSL) is a family of languages that describe how XML-encoded files should be formatted (for display) or transformed. It has three members:

  • XSLT (XSL Transformations), which converts XML documents from one syntax to another (e.g. XML to another XML, or XML to HTML). The output may or may not be XML.
  • XSL-FO (XSL Formatting Objects), used to specify the visual format in which an XML document should be presented. Mainly used to produce PDF documents.
  • XPath (XML Path Language), a non-XML syntax used to address or refer to parts of an XML document.

The three specifications are official W3C recommendations. Some are supported natively by browsers (Mozilla, Internet Explorer). In practice CSS is often used instead — 100% compatible for styling although with a different syntax.

XSLT template example

Templates are applied in the order they are declared in apply-templates. When two templates match the same node either an explicit priority decides or the most specific template wins. To apply templates to child nodes, add <xsl:apply-templates> inside the parent template; with select="//*" you match every node.

<xsl:template match="/">
<xsl:apply-templates select="//*">
<xsl:apply-templates select="//*" mode="2">
</xsl:template>
<xsl:template match="*">
<hello>
<xsl:value-of select="name()"/>
</hello>
</xsl:template>
<xsl:template match="*" mode="2">
<hello2>
<xsl:value-of select="name()"/>
</hello2>
</xsl:template>

This applies both templates to the message one after the other. You can read attributes with <xsl:value-of select="@node"> and apply templates to them with <xsl:apply-templates select="@node">. Instead of iterating node-by-node checking for pattern matches, <xsl:for-each> traverses the whole document applying a pattern. Values can be injected into the output XML with <xsl:element name=""> and attributes with <xsl:attributes name="">. copy copies only the current node; copy-of copies it with all its children.

Java parsing

In the Java world, the JAXP specification parses XML messages into objects. Two language-independent specifications sit underneath: SAX, for accessing parts of the document as an event stream, and DOM, which builds the entire document tree in memory. JAXP implements both. Java implementations include SAXON (SAX) and Xerces (DOM). JDOM is a Java-only implementation that makes elements easier to manipulate, essentially treating them like items in a List.

Finally, JAXB is the Java specification for marshalling and unmarshalling XML documents into objects. It lets you map Java objects directly to XML documents based on a defined XSD. There are two implementations in Java: the reference implementation and JAXME. There is also XMLBeans, which does the same job but does not follow the JAXB standard.
