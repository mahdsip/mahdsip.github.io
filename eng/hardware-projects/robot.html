My Robots

DIY robotics projects

Tiki - Raspberry Pi voice assistant

Tiki is my Raspberry Pi-based assistant robot. It answers questions using the Jasper project, an open-source platform for building custom voice assistants.

Tiki's features:

  • Offline voice recognition using the Jasper project
  • Answers to basic questions
  • HC-SR04 ultrasonic sensor for obstacle detection
  • Solar panel + LiPo battery for energy autonomy
  • Tracked chassis for mobility on all surfaces
  • Runs on a Raspberry Pi

Hexapod spider robot

A six-legged robot built from a DIY kit that I assembled and programmed. It uses servo motors to control each leg independently, allowing different gait modes.

Specs:

  • 18 servo motors (3 per leg)
  • Arduino controller
  • Programmable movements
  • Bluetooth remote control

Mini bug robots with clothespins

Inspired by the Neoteo tutorial, these mini robots use wooden clothespins, vibration motors and button cells. They are ideal projects to get kids started with robotics — simple, cheap and surprisingly fun to watch move around.

Materials:

  • Wooden clothespins
  • Vibration motors (from old mobile phones)
  • CR2032 batteries or solar cell
  • Sticky tape and glue
