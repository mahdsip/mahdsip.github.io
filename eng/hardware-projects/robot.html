My Robots

DIY robotics projects

Tiki - Raspberry Pi voice assistant

Tiki is my Raspberry Pi-based assistant robot. It answers questions using the Jasper project, an open-source platform for building custom voice assistants.

Tiki's features:

  • Offline voice recognition
  • Answers to basic questions
  • Home device control
  • Runs on a Raspberry Pi 3

Hexapod spider robot

A six-legged robot built from a DIY kit that I assembled and programmed. It uses servo motors to control each leg independently.

Specs:

  • 18 servo motors (3 per leg)
  • Arduino controller
  • Programmable movements
  • Bluetooth remote control

Mini robots with clothespins

Inspired by the Neoteo tutorial, I built several mini robots using wooden clothespins, vibration motors and button cells. They are ideal projects to get kids started with robotics.

Materials:

  • Wooden clothespins
  • Vibration motors (from old mobile phones)
  • CR2032 batteries
  • Sticky tape and glue
