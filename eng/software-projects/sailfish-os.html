Sailfish OS on Xperia 10

Running Sailfish OS with Nextcloud and PineWatch integration

My history with alternative mobile operating systems

My relationship with alternative mobile operating systems goes back a long time. It all started with the Nokia N810 Internet Tablet, a groundbreaking device running Maemo, a Linux-based system.

Later on came the legendary Nokia N9 with MeeGo, a masterpiece of design and usability.

Sailfish OS: the heir to MeeGo

I currently use a Sony Xperia 10 running the latest version of Sailfish OS.

Integration with Nextcloud

I've set up my Xperia 10 to sync with my Nextcloud server:

  • Contacts via CardDAV
  • Calendar via CalDAV
  • Files and photos
  • Notes and tasks

PineWatch pairing

I've paired my Xperia 10 with my PineWatch running InfiniTime OS.
